## 📖 The Story

It was a Sunday evening. The week ahead felt like an ocean — vast, overwhelming, and full of things that *needed* to get done. Assignments piling up, practice sets waiting, links bookmarked but never opened, notes scribbled on random pages.

**"There has to be a better way,"** I thought.

And so, **Weekly Targets To-Do** was born — not just another to-do app, but a *weekly command center*. A place where every Monday through Sunday has its own lane, every task has its own story, and nothing slips through the cracks.

No sign-ups. No servers. No nonsense. Just open, plan, and **conquer your week**.

---

## ✨ What Makes It Special?

> *"A task without a day is just a wish."*

Most to-do apps throw everything into one big list. This one doesn't. Here, your week is laid out like a **visual board** — seven columns, seven days, zero chaos.

### 🎯 Features at a Glance

| Feature | Description |
|---|---|
| 📅 **7-Day Board View** | See your entire week at a glance with Monday-to-Sunday columns |
| ✅ **One-Click Complete** | Satisfying checkbox animations to mark tasks done |
| 🔗 **Link Attachments** | Attach URLs to any task — no more lost bookmarks |
| 📎 **File Attachments** | Drag and drop files right onto your tasks |
| ✏️ **Edit Anything** | Full modal editor to update title, day, notes, links, and files |
| 📊 **Week Progress** | Live progress percentage across all your tasks |
| 🧹 **Clear Completed** | One click to sweep away finished tasks |
| 🔄 **Reset Week** | Fresh start whenever you need one |
| 💾 **Auto-Save** | Tasks persist in `localStorage` — refresh and they're still there |
| ⌨️ **Keyboard Friendly** | `Enter` to add, `Escape` to close modals |

## 🎮 How to Use

> *A quick walkthrough for the curious mind.*

**Creating a Task**
1. Type a task title in the **"Create a task"** form
2. Pick the **day of the week** from the dropdown
3. *(Optional)* Add a due date, notes, a link, or file attachments
4. Hit **"Add to day"** — watch it appear in the board!

**Managing Tasks**
- **✅ Complete** → Click the checkbox on any task card
- **✏️ Edit** → Click the **Edit** button to open the detail modal
- **🗑️ Delete** → Click **Delete** on a task card or inside the modal
- **🧹 Clear completed** → Removes all finished tasks in one sweep
- **🔄 Reset week** → Nuclear option — starts completely fresh

**Keyboard Shortcuts**
| Key | Action |
|---|---|
| `Enter` | Submit the task form |
| `Escape` | Close the edit modal |

## 🧠 Behind the Scenes

Here's a peek at how the magic works:

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│   User UI   │────▶│  App State   │────▶│ localStorage│
│ (index.html)│     │ (script.js)  │     │  (Browser)  │
└─────────────┘     └──────────────┘     └─────────────┘
       ▲                    │
       │                    ▼
       └────────── Re-render on
                   every change
```

- **State-driven rendering** — Every action updates `appState`, triggers `renderWeek()`, and the DOM rebuilds
- **Persistent storage** — Tasks are serialized to `localStorage` on every render cycle
- **Zero-dependency** — No React, no Vue, no jQuery. Pure DOM APIs
